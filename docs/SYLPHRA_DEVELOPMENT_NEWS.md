# Sylphra — Development News

This feed is included only in beta and development builds. Stable/release builds do not show the News destination.

## Current focus
- [IN PROGRESS] Skin Studio: validate first-install player-model preparation and the expanded 3D preview on a physical Android device.
- [IN PROGRESS] Launcher identity: adapt the Java Edition launcher's dark-and-green visual language while keeping Sylphra's own layout and interaction design.
- [PROPOSED] Add a contributor-friendly testing checklist for Android devices, graphics backends, skins and multiplayer.

## How to read development status
- PROPOSED: under consideration; not implemented.
- IN PROGRESS: being investigated or implemented.
- APPLIED — UNVERIFIED: code is present but has not passed the required checks or device test.
- VERIFIED: the named checks or device behaviour passed; the exact evidence is recorded in the development log.

## Testing and contributing
Development APKs are experimental. Back up worlds before testing, report the APK build/commit, Android version, device/GPU, reproduction steps and logs, and distinguish observations from guesses. Do not share account tokens, passwords or private session files.
